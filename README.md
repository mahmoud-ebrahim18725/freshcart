# 🛒 Supermarket Cart

A modern supermarket shopping cart application built with React.

The project focuses on managing cart state, fetching products, filtering and sorting products, and persisting cart data using LocalStorage.

## ✨ Features

- Display products from an API
- Add products to the cart
- Increase and decrease product quantity
- Remove products from the cart
- Clear the entire cart
- Prevent adding more items than available stock
- Calculate total items and total price
- Search and filter products
- Sort products
- Persist cart data using LocalStorage
- Loading and error states
- Responsive design
